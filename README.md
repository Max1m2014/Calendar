# Медиа-виджет (стиль One UI)

Виджет 4×2 для главного экрана Galaxy: слева обложка (трек, превью видео YouTube и т. п.),
справа приложение, название, исполнитель, прогресс и кнопки ⏮ ⏯ ⏭.
Фон — размытая затемнённая обложка, как у плеера в шторке One UI.

Если сузить виджет до 2×2 (ширина меньше ~200 dp), он переключится на квадратный вид:
обложка на весь виджет, сверху приложение и название, снизу прогресс и кнопки.
Фон 4×2 переключается в приложении: адаптивный (из обложки), тёмный,
светлый/тёмный по теме телефона, AMOLED-чёрный.

Порог меняется в `WidgetRenderer.SQUARE_MAX_WIDTH_DP`.

## Сборка

**Вариант A — без Android Studio (GitHub Actions):**
1. Создай приватный репозиторий на GitHub и загрузи туда содержимое папки.
2. Вкладка *Actions* → «Build APK» соберётся сам → в результатах скачай `MediaWidget-apk`.

**Вариант B — Android Studio:** Open → папка `MediaWidget` → Build → Build APK(s).

## Установка на телефон
1. Установи APK (разрешить установку из этого источника).
2. Открой «Медиа-виджет» → «Разрешить доступ к медиа» → включи переключатель.
   - Если переключатель серый: Сведения о приложении → ⋮ → «Разрешить ограниченные настройки»
     (так Android 13+ защищает APK, установленные не из магазина).
3. «Добавить виджет на экран» (или долгое нажатие на экран → Виджеты → Медиа-виджет).

## Как это устроено
- `MediaListenerService` — слушатель уведомлений; нужен только для доступа к медиасессиям
  других приложений. Отслеживает смену трека/паузы и двигает прогресс раз в секунду
  (только при включённом экране и активном воспроизведении).
- `WidgetRenderer` — собирает RemoteViews: обложка, размытый фон, тексты, прогресс.
- `MediaWidgetProvider` — кнопки. Если активной сессии нет, ▶ отправляет системную
  медиакнопку — продолжится последний плеер.
- Тап по обложке или названию открывает приложение-плеер.

Внешних зависимостей нет — только Android SDK (minSdk 31, target 35).
